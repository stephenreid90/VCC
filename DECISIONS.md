# DECISIONS — the ratified register

**Purpose: to stop settled questions being reopened.** One line per decision, with the
date it was made and a pointer to where the reasoning lives. This is the file to check
*before* proposing a method, not after.

**How to use it.** If a question you are about to open appears here, it is closed —
read the linked reasoning and proceed on that basis. If you believe a decision is
wrong, say so explicitly and ask Stephen to revisit it; do not quietly re-derive an
alternative. Reopening without saying so is the single largest source of drift in this
project.

**How to maintain it.** Add a row the moment Stephen ratifies something. Never delete a
row — supersede it, and leave the old one with `SUPERSEDED` and a pointer to the row
that replaced it. The history of what we used to think is part of the record.

Status values: **FIRM** (settled, do not reopen) · **PROVISIONAL** (working assumption,
flagged for revisit when named evidence arrives) · **SUPERSEDED**.

**Sizing note on D-42, recorded 16 September 2026.** The diagnostic D-42 proposes was built
and run across all eighteen valuations before the decision itself was ruled, because its
output is the evidence the ruling needs. It computes the terminal return on NEW capital from
the growth identity `g = return x reinvestment_rate` on production engine output, against two
benchmarks: the cost of capital, which is D-42's question, and the return the final explicit
year actually earns, which is M14's. Both constructions were lifted from
`tests/dcf/harness/replica.py` rather than reinvented, and moved onto the engine path because
a published number cannot come from a harness (D-51, standing rule 4). Regenerated by
`scripts/size_terminal_returns.py`, committed as `design/methodology/terminal_return_sets.yaml`,
asserted by `tests/dcf/test_terminal_return_sets.py`. Nothing moved — it observes only.

Three things it found, in order of size. **CSL's terminal asserts a 61–73% return on new
capital** against a discount rate of 8.75%, because `terminal_capex_pct_revenue` equals
`da_pct_revenue` exactly, net terminal capex is therefore zero, and the only reinvestment left
is working capital at about 1.05% of revenue. That is not a new defect: it is D-53
unimplemented, now with a number on it (M15). **WBC's Stagflation terminal ROE sits 401bp
above** what its final explicit year earns, a perpetual recovery assumption that nothing
declares, on the scenario whose terminal is the largest share of value in the project (M14).

8.88% — which is the diagnostic discriminating rather than firing on everything, and is the
best evidence that D-42 is worth ratifying. The three DNL scenarios above the line, and all
six WBC scenarios, owe the §10.6-compliant defended exception D-42 would require; that
obligation is not in force until D-42 is ruled.
